PDF 페이지 정리

Organize PDF pages

썸네일을 드래그해 순서를 바꾸고, 페이지를 삭제하거나 회전한 뒤 새 PDF로 저장합니다.

Drag thumbnails to reorder, delete or rotate pages, then save as a new PDF.

사용 방법

How it works

  1. PDF 선택Select a PDF정리할 PDF를 올리면 모든 페이지가 썸네일로 표시됩니다.All pages appear as thumbnails.
  2. 편집Edit드래그로 순서 변경, ✕ 로 삭제, ⟳ 로 회전합니다.Drag to reorder, ✕ to delete, ⟳ to rotate.
  3. 저장Save실행을 누르면 편집된 새 PDF가 다운로드됩니다.Click run to download the edited PDF.

자주 묻는 질문

FAQ

삭제한 페이지를 되돌릴 수 있나요?Can I undo a delete?

저장 전에는 ↺ 버튼으로 복원할 수 있습니다. 원본 파일은 변경되지 않으니 언제든 다시 시작할 수 있습니다.

Before saving, press ↺ to restore. Your original file is never modified.

페이지를 다른 PDF에서 가져올 수 있나요?Can I add pages from another PDF?

먼저 “PDF 합치기”로 파일을 합친 뒤 이 도구로 정리하면 됩니다.

Merge the files first with “Merge PDF”, then organize the result here.

큰 파일도 되나요?Does it work for large files?

네, 다만 페이지가 많으면 썸네일 생성에 시간이 걸릴 수 있습니다.

Yes, though thumbnails for very long documents take a moment.
