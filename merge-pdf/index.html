PDF 합치기

Merge PDF

여러 개의 PDF를 드래그해서 순서를 정하고 하나의 파일로 합칩니다. 100% 무료, 파일은 서버로 전송되지 않습니다.

Drag to order your PDFs and combine them into a single file. 100% free, nothing is uploaded.

사용 방법

How it works

  1. PDF 파일 선택Select PDFs합칠 PDF 파일을 2개 이상 올립니다.Add two or more PDF files.
  2. 순서 정하기Set the order파일을 드래그해서 원하는 순서로 배치합니다.Drag files to arrange them.
  3. 합치기 실행Merge버튼을 누르면 즉시 합쳐진 PDF가 다운로드됩니다.Click the button and download the merged PDF.

자주 묻는 질문

FAQ

파일 개수나 용량 제한이 있나요?Is there a file limit?

개수 제한은 없고 파일당 200MB까지 가능합니다. 처리 속도는 사용 중인 기기 성능에 따라 달라집니다.

No file-count limit; each file can be up to 200 MB. Speed depends on your device.

파일이 서버에 업로드되나요?Are my files uploaded?

아니요. 모든 처리는 브라우저 안에서 이루어지며 파일은 사용자의 기기를 떠나지 않습니다.

No. Everything runs inside your browser and your files never leave your device.

암호가 걸린 PDF도 합칠 수 있나요?Can I merge password-protected PDFs?

암호(열기 비밀번호)가 설정된 PDF는 현재 지원하지 않습니다. 먼저 암호를 해제한 뒤 이용해 주세요.

Not yet. Please remove the password first.
