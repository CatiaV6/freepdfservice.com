PDF 페이지 번호 넣기

Add page numbers

원하는 위치와 형식으로 모든 페이지(또는 지정한 범위)에 페이지 번호를 넣습니다.

Number every page, or just a range, in the position and format you want.

사용 방법

How it works

  1. PDF 선택Select a PDF번호를 넣을 PDF를 올립니다.Add the PDF.
  2. 위치·형식 설정Set position & format위치, 시작 번호, 형식({n} / {total}), 글자 크기, 여백을 정합니다.Position, start number, format ({n} / {total}), size and margin.
  3. 적용Apply실행을 누르면 번호가 들어간 PDF를 받습니다.Click run to download the numbered PDF.

자주 묻는 질문

FAQ

표지에는 번호를 빼고 싶어요How do I skip the cover page?

페이지 범위에 2-100 처럼 입력하면 1페이지를 제외할 수 있습니다. 시작 번호도 함께 조절하세요.

Enter a range like 2-100 to exclude page 1, and adjust the start number if needed.

“{n} 페이지”처럼 한글도 되나요?Can the format include Korean?

네. 형식에 한글이 포함되면 한글 폰트를 자동으로 사용합니다.

Yes. Korean characters switch to the embedded Korean font automatically.

가로 페이지도 올바르게 들어가나요?Do rotated pages work?

네. 회전된 페이지도 화면 기준으로 올바른 위치와 방향에 번호가 들어갑니다.

Yes. Numbers follow the on-screen orientation of rotated pages.
