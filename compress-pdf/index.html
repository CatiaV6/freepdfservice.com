자주 묻는 질문

FAQ

기본 모드와 강력 모드의 차이는?Basic vs. Strong?

기본 모드는 PDF 내부 구조를 최적화해 텍스트와 품질을 그대로 유지합니다(줄어드는 폭은 파일마다 다름). 강력 모드는 각 페이지를 JPG 이미지로 변환해 스캔본·사진 위주 PDF를 크게 줄이지만 글자 선택과 검색이 불가능해집니다.

Basic optimizes the internal structure and keeps text intact (savings vary). Strong converts each page to a JPG image: great for scans and photos, but text is no longer selectable.

왜 거의 줄어들지 않나요?Why did it barely shrink?

이미 최적화된 PDF나 텍스트 위주 PDF는 기본 모드로 더 줄이기 어렵습니다. 이 경우 강력 모드를 사용해 보세요.

Already-optimized or text-only PDFs have little to gain in Basic mode. Try Strong mode.

원본보다 커지면 어떻게 되나요?What if the result is bigger?

결과가 원본보다 크면 원본 파일을 그대로 제공합니다.

If the output would be larger, the original file is returned unchanged.
