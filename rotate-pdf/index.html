PDF 회전

Rotate PDF

페이지 썸네일을 보며 원하는 페이지만, 또는 전체를 한 번에 회전합니다.

See thumbnails and rotate individual pages or the whole document at once.

사용 방법

How it works

  1. PDF 선택Select a PDF회전할 PDF를 올리면 페이지 썸네일이 표시됩니다.Page thumbnails appear after loading.
  2. 회전Rotate각 페이지의 회전 버튼을 누르거나 “전체 90° 회전”을 사용합니다.Use the per-page rotate button or “Rotate all 90°”.
  3. 저장Save실행을 누르면 회전이 영구 적용된 PDF를 받습니다.Click run to download the PDF with rotation applied.

자주 묻는 질문

FAQ

회전이 뷰어에서 바뀌지 않아요The rotation doesn’t show in my viewer

이 도구는 PDF 파일 자체에 회전 정보를 저장하므로 모든 뷰어에서 회전된 상태로 열립니다. 이전 파일이 캐시된 경우 새로 받은 파일을 열어 주세요.

Rotation is written into the PDF itself, so every viewer opens it rotated. Make sure you open the newly downloaded file.

품질이 떨어지나요?Does it lose quality?

아니요. 페이지 내용은 그대로이며 방향 정보만 변경됩니다.

No. Only the orientation attribute changes; page content is untouched.

여러 파일을 한 번에 회전할 수 있나요?Can I rotate several files at once?

현재는 한 번에 한 파일씩 처리합니다.

Currently one file at a time.
