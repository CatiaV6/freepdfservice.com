자주 묻는 질문

FAQ

한글 워터마크가 되나요?Does Korean text work?

네. 한글이 포함되면 나눔고딕 폰트를 자동으로 사용해 깨짐 없이 표시됩니다.

Yes. Korean text automatically uses the embedded Nanum Gothic font.

이미지 로고 워터마크도 가능한가요?Can I use an image/logo?

현재는 텍스트 워터마크만 지원하며 이미지 워터마크는 준비 중입니다.

Only text watermarks for now; image watermarks are planned.

워터마크를 나중에 제거할 수 있나요?Can the watermark be removed later?

워터마크는 페이지 내용 위에 그려지므로 원본 파일을 따로 보관해 두세요.

It is drawn into the page content, so keep your original file.
